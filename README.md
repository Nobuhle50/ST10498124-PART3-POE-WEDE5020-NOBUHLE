## Project Overview
A multi-page website for Hlehle's Orphanage, a non-profit organisation in Pretoria that cares for orphaned and vulnerable children. The site provides information about the organisation, events, sponsorship opportunities and contact details.

## Website Goals & Objectives
- Raise awareness about the orphanage
- Encourage donations and sponsorships
- Provide clear information about programmes and how to help
- Create an accessible, mobile-friendly experience

## Key Features
- Responsive design (desktop, tablet, mobile)
- Clear navigation across all pages
- Semantic HTML5 structure
- External CSS with modern layout (Flexbox & Grid)
- Hover effects and visual hierarchy

## Pages
- `index.html` – Homepage
- `about.html` – About the organisation
- `events.html` – Events & programmes
- `sponsorship.html` – How to support us
- `contact.html` – Contact details & hours
